# App-Wide Icon Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply a consistent `lucide-react` icon language to navigation, actions, and notice/empty-state patterns across the whole app, and extract two shared UI primitives (`Callout`, `EmptyState`) that the notice/empty-state migrations need.

**Architecture:** No new subsystems. Two new files under `src/components/` (shared UI primitives, matching the existing placement of `site-nav`, `follow-button`). Every other change is a small, self-contained edit to an existing component: import an icon, add it inline next to existing text/inside an existing button, or replace an inline box with `<Callout>`/`<EmptyState>`.

**Tech Stack:** `lucide-react` (`^1.34.0`, already a dependency), React 19, Testing Library/Vitest.

**Spec:** `docs/superpowers/specs/2026-08-27-icon-pass-design.md`

## Global Constraints

- Icon library: `lucide-react` only, imported by name (e.g. `import { Pencil } from 'lucide-react'`).
- Sizing: `size={14}` for icons placed inline next to text. `size={18}` only for the takeoffs directory's `ViewToggle` buttons (standalone icon-bearing controls with larger tap targets — the one place the spec calls for 18px).
- Color: no icon gets an inline color or a new Tailwind color class. Every icon sits inside an element already carrying `opacity-70`/`opacity-60`/etc., or is given `opacity-70`/`opacity-50` directly matching its neighboring text — never a new accent color.
- Every decorative icon (one placed next to visible text) gets `aria-hidden="true"`. Icons never change any element's accessible name — lucide-react renders a plain `<svg>` with no default role or text, so this is enforced by both the icon markup and the explicit `aria-hidden`.
- External links (leaving the app) get a **trailing** icon (`ExternalLink`, after the text). Every other icon is **leading** (before the text).
- Existing Tailwind classes are never removed or altered beyond what's needed to lay the icon out (typically adding `flex items-center gap-1` / `gap-1.5`, or `inline-flex` for an `<a>` sitting inline within running text). Do not change padding, color, border, or font-size classes on any element touched.
- New shared components live in `src/components/<name>/index.tsx`, matching `site-nav`, `follow-button`, `flown-sites-map`, `takeoffs-map`.
- Every task must leave `npx tsc --noEmit` clean and the full test suite green before committing.

```tsx
// src/components/callout/index.tsx
import type { ReactNode } from 'react'
import { AlertTriangle } from 'lucide-react'

type CalloutTone = 'warning' | 'error'

type CalloutProps = {
  tone: CalloutTone
  children: ReactNode
}

// Two existing box shapes this generalizes, kept verbatim per tone rather than merged into one:
// the warning boxes (e.g. flight-feed-view.tsx's FailedPilotsNotice) are `p-4 text-sm` with plain
// block-flow children; error.tsx's box is `p-6` with a `flex-col gap-3` stack of heading/message/
// button. TONE_CONTENT_CLASSES preserves each tone's original internal layout inside a nested div,
// while the outer div adds the horizontal `flex items-start gap-3` needed to place the icon beside
// that content without disturbing either tone's original stacking.
const TONE_BOX_CLASSES: Record<CalloutTone, string> = {
  warning: 'flex items-start gap-3 rounded-md border border-amber-500/30 bg-amber-500/5 p-4 text-sm',
  error: 'flex items-start gap-3 rounded-md border border-red-500/30 bg-red-500/5 p-6',
}

const TONE_CONTENT_CLASSES: Record<CalloutTone, string> = {
  warning: 'flex-1',
  error: 'flex flex-1 flex-col items-start gap-3',
}

export function Callout({ tone, children }: CalloutProps) {
  return (
    <div className={TONE_BOX_CLASSES[tone]}>
      <AlertTriangle aria-hidden="true" className="mt-0.5 shrink-0 opacity-70" size={14} />
      <div className={TONE_CONTENT_CLASSES[tone]}>{children}</div>
    </div>
  )
}
```
